# Test Forge · SGCS2026

Plataforma educativa sobre **Sistemas de Gestión de Calidad del Software**, desarrollada por el grupo **Test Forge** (EPET 2026).

La página aborda:

- Gestión de la calidad: fundamentos, normas ISO/IEC 9126 y 25000, técnicas y herramientas.
- Procesos de desarrollo: ciclo de vida (SDLC) y modelos tradicionales (Cascada, Modelo V, Iterativo).
- Metodologías ágiles: Scrum, Kanban, XP y el Manifiesto Ágil.
- Recursos: glosario, preguntas frecuentes, comparador de metodologías y encuesta.
- Sobre nosotros y formulario de contacto.
